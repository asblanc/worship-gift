# Worship Gift – Cline Workspace Rules

## Vision
- Site web premium pour le mouvement gospel Worship Gift.
- Atmosphère : spirituelle, élégante, chaleureuse, centrée sur la louange.

## Stack technique
- Next.js (App Router, TypeScript).
- Tailwind CSS, Shadcn UI, Framer Motion.
- Supabase pour auth + base de données (profils, événements, billets).
- UI pensée mobile-first.

## Design
- Fond : noir (#000000) ou noir doux (#0D0D0D).
- Texte : blanc (#FFFFFF) + gris clair (#B0B0B0) pour le secondaire.
- Accent principal : or (#C9A84C), accent lumineux (#F0CB6A).
- Titres : Cormorant Garamond.
- Corps : Inter.
- Style : épuré, lisible, avec animations douces (pas flashy).

## Fonctionnalités clés
- Pages : Accueil, À propos, Galerie, YouTube/Live, Billetterie, Contact.
- Auth : inscription/connexion, espace personnel (profil + billets).
- Intégration Supabase : tables profiles, events, tickets.
- Intégration YouTube : liste des vidéos + live si disponible.

## Manière de travailler
- Toujours proposer un plan par étapes avant de modifier beaucoup de fichiers.
- Exécuter une seule grande étape à la fois et attendre ma validation.
- Expliquer en français ce qui a été fait (fichiers modifiés, scripts à lancer).
- Priorité : accessibilité, performance, responsive.
