## Objectif
Assurer une cohérence visuelle forte pour Worship Gift : noir/or, typographie élégante, animations douces.

## Règles UI
- Utiliser majoritairement un fond noir (#000000 ou #0D0D0D).
- Texte principal blanc (#FFFFFF), texte secondaire gris clair (#B0B0B0).
- Accent or (#C9A84C) pour boutons, liens importants, survols.
- Police titres : Cormorant Garamond, avec letter-spacing léger pour un effet premium.
- Police corps : Inter, tailles confortables (16–18px mini en desktop).
- Style : épuré, lisible, avec animations douces, pas agressives.

## Composants à privilégier
- Hero section pleine hauteur, avec overlay dégradé + texte centré.
- Cards d’événements avec image, titre, date, lieu, bouton CTA.
- Galerie masonry avec hover overlay et légende.
- Navbar translucide (glassmorphism) avec sticky top.

## Animations
- Utiliser Framer Motion pour : fade-in, slide-up, hover scale léger.
- Préserver de bonnes performances (éviter les animations permanentes lourdes).
